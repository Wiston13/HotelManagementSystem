# HotelManagementSystem

**中小型連鎖商旅訂房與住宿管理系統**

## 專案簡介

HotelManagementSystem 是一套供中小型連鎖商旅使用的中央訂房與住宿管理系統。

系統讓顧客、分館員工與總系統管理員共用一致的資料基礎，串接線上訂房、可售房量、入住、退房與清潔交接，降低訂單、住房紀錄及實體房間狀態彼此不一致的情況。

目前專案正進行第一版核心流程整合。

## 系統設計目的

本專案不只提供個別資料的新增、查詢與修改，而是整合一條完整的住宿營運資料流：

**訂房 → 可售房量 → Check-in → 實體房號 → Check-out → 清潔**

系統透過訂單、住房紀錄、房型與實體房間之間的關聯，維持以下資料一致性：

- 顧客訂房時選擇房型，入住時才由分館員工指派實體房號。
- 正式訂單會依住宿日期占用對應房型的可售房量。
- Check-in 建立實際住房紀錄。
- Check-out 完成訂單並將房間轉為待清潔。
- 清潔完成後，房間才可再次指派入住。

## 使用者角色

### 顧客

免登入查詢分館與可售房型、完成模擬付款訂房，並以訂單編號與聯絡電話查詢訂單。

### 分館員工

處理所屬分館的訂單查詢、取消、Check-in、Check-out，以及房間供應與清潔狀態。

### 總系統管理員

跨館管理分館、房型、固定價格、實體房間與分館員工帳號，並預覽及匯出訂單資料、查詢基本操作紀錄。

## 核心業務流程

第一版以完成下列可重複操作的營運閉環為目標：

1. 總系統管理員建立分館、房型、固定價格、實體房間與分館員工。
2. 顧客依分館、住宿日期與入住人數查詢可售房型。
3. 顧客完成模擬信用卡全額付款，系統建立正式訂單並占用房量。
4. 顧客抵達後，由分館員工核對訂單並指派原訂房型的合格房間。
5. Check-in 成功後建立住房紀錄，保存實際房號與入住資料。
6. 分館員工辦理 Check-out，完成住房與訂單，房間轉為待清潔。
7. 清潔完成後，分館員工將房間恢復為已清潔，使其可再次指派。

## 技術棧

- **程式語言：** C#
- **執行平台：** .NET 10
- **Web 框架：** ASP.NET Core MVC
- **資料存取：** Entity Framework Core
- **資料庫：** Microsoft SQL Server
- **前端：** Razor Views、Bootstrap、JavaScript、jQuery
- **版本控制與協作：** Git、GitHub

## 專案結構

- `Controllers/`：接收使用者操作並協調 MVC 流程。
- `Services/`：跨功能共用的業務邏輯與服務。
- `Models/`：資料庫實體、Entity Framework Core Context 與畫面模型。
- `Views/`：顧客、分館員工及總系統管理員使用的 Razor Views。
- `database/`：資料庫 Schema、基準資料、開發情境與驗證腳本。
- `wwwroot/`：CSS、JavaScript、圖片及前端套件等靜態資源。

## 目前開發狀態

專案目前處於第一版核心流程整合階段。

### 主要已整合

- 第一版核心資料表、關聯、約束與 Entity Framework Core 資料模型。
- SQL Server 連線及可重建的開發資料與驗證腳本。
- 統一的 `Asia/Taipei` 業務時間來源與逾期未入住訂單補判。
- 分館員工工作首頁，以及 Check-in、Check-out 的核心資料流程。

### 持續整合中

- 顧客查房、可售房量、模擬付款、訂單建立與訂單查詢。
- 員工登入、分館訂單處理與房間狀態管理。
- 總系統管理員的基礎資料管理、訂單匯出與操作紀錄查詢。
- 各角色功能串接及第一版完整營運流程驗證。

## Git 協作流程

專案以 `develop` 作為功能整合分支，團隊成員透過功能分支與 Pull Request 協作：

**develop → feature branch → Pull Request → review → merge into develop**

各功能在獨立分支開發與檢查後，再合併回 `develop` 進行整合。
